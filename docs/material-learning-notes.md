## 生成与质量检查

1. **原文**：沿用 `text-polish-v1` 的纯文字策略。文件原文、阅读笔记与检索证据分别保存。来源长块/备注拆为带原块 ID 和偏移的片段，保留全文。
2. **知识规划**：模型读取完整文字，长资料先分组规划再合并；用短别名传递 ID，服务器恢复真实来源。按主题规划讲解目标与知识要点。教学安排、重复目录、空标题不单独构成知识章节；其中的有效内容融入对应章节。
3. **章节整理**：同主题短块尽量一起处理，按输入字符预算拆长章节；块数配置为软上限，另有 100 块硬上限和 18,000 字符上限。全文上下文仅传章节标题，不将其他章节的知识清单当作本批证据。
4. **受控富文本**：标题、解释段落、列表、代码、表格；`**关键词**` 与行内代码转换为编辑器格式。后台保留来源引用及 source/explanation/summary 类别；模型稿不作为原始检索证据。
5. **逐批复核**：程序检查结构、来源、逐元素数字、原文代码和覆盖；每批都做语义复核，检查实质知识遗漏、条件/否定变化与新增具体事实。允许正确的同义改写、概念解释和合理归纳；建议与实质错误分别处理。最多一次批内修复。
6. **全文整理**：按有界分组检查主题重复、标题层级、术语与衔接。只对涉及批次修复，并重新做来源复核，随后再次全文检查。程序合并同章标题与完全相同的重复正文，合并其来源映射。
7. **发布**：完整检查通过才生成新版本。初始原文未改动时可成为当前阅读版本；已有阅读/编辑版本时保留为候选。重生成、应用候选和编辑保存不更新原文索引或知识库。

## 不完整资料

纯图片与扫描件没有原生文字时不调用模型，不使用 OCR 或视觉模型。

只提取到操作名、示例标题而没有实际正文时，不生成成串空小节、不补猜截图里的代码。来源缺口通过 `source_gap` 保留记录，并在整份笔记末尾集中说明。`course_admin` 用于预习等课程事务，独立知识不得按此删除。

表格、命令和参数必须有来源支持；辅助解释不能变成新增技术事实、考试预测或无依据的代码。学习笔记的完整程度仍受可提取文字影响。

## 任务、缓存与版本

- 原文提取、索引和 AI 学习笔记使用独立队列；资料 worker 同时承载润色队列。
- 目录规划按完整输入/配置哈希保存检查点。通过复核的批次在完成时立即落库，单批失败不丢掉其他批次结果。
- 批次缓存包含用户、资料、源哈希、实际模型/地址、提示词和结构版本、章节上下文及来源块列表。变更规则后不复用旧规则缓存。
- 每代任务固化生成参数。执行时核对模型和规则；配置已变化时要求明确重新生成，不混用旧任务和新模型。
- 请求级全局并发槽同时约束规划、正文和复核请求；不将任务并发与批次并发相乘为无界请求。
- 发布检查租约、源哈希、原文版本与任务代次。候选发布占用独立版本号，后续用户保存不会与候选版本号冲突。
- 021 迁移移除用户/缓存键的唯一约束，保留每代失败与成功记录；缓存只复用已通过复核的结果，并物化到当前任务。

## 阅读与编辑

正文以知识章节阅读，文档标题不重复进入目录；目录展示两级知识标题。表格支持单元格文字编辑，保存后可恢复表头、单元格、加粗与代码。

“查看来源”集中打开不可变原文；后台来源映射继续保存。“文档信息”折叠展示阅读、检索和知识版本。普通保存与轮询不触发模型调用。

已有笔记不会被自动批量改写。使用“基于原文重新整理”生成新版；已有正文时查看并显式应用候选。

## 配置与本地启用

```dotenv
MATERIAL_PPTX_PARSE_MODE=text_only_polished
MATERIAL_NOTE_POLISH_MODEL_ID=default
MATERIAL_NOTE_POLISH_PROMPT_VERSION=material-learning-v2
MATERIAL_NOTE_POLISH_REVIEW_MODE=always
MATERIAL_NOTE_POLISH_TIMEOUT=180
MATERIAL_NOTE_POLISH_MAX_OUTPUT_TOKENS=16384
MATERIAL_NOTE_POLISH_BATCH_BLOCKS=24
MATERIAL_NOTE_POLISH_CONCURRENCY=3
```

`MODEL_ID` 选择已配置的文本提供商；代码内 v2 始终做语义复核，兼容环境里遗留的 `on_check_failed` 字符串，但不再跳过复核。

本机最终采用 `MATERIAL_NOTE_POLISH_MODEL_ID=deepseek`、`MATERIAL_NOTE_POLISH_MODEL=deepseek-v4-pro`。显式模型名复用所选提供商的账号与地址；只影响资料学习笔记，聊天中原有的 `deepseek-flash` 配置保持原值。

启动前应用迁移，重启后端与资料 worker。前端为 Vite 开发服务时热更新；构建发布使用 `npm run build`。本机已在 65,593,860 字节的数据库备份后应用 021 迁移，备份位于 `backups/before-learning-note-v2-20261115.dump`，已校验归档目录可读取。
