# MVP 开发积压清单

基线：[MVP 路线图](plans/mvp-roadmap.md) 与 [ADR-0001](decisions/0001-mvp-defaults.md)。任务按
“先让学生安全地拥有课程与资料，再形成可确认资产，再作答、订正、报告”的用户闭环排序；同一
里程碑内也按技术前置关系排列。每张卡预期为一次聚焦开发（约 1 小时至半天）。

## 统一命令与状态

- **BE**：`uv run pytest -q && uv run ruff check src tests examples eval && uv run ruff format --check src tests examples eval`
- **FE**：在 `frontend` 目录运行 `npm run build`；引入前端 E2E 后，替换为项目的全量 E2E 命令。
- **状态**：`已完成`、`待验收`、`待开发`、`阻塞`。`待验收` 表示代码存在但未完成该卡指定的
  集成/人工验证；不应据此宣布 PRD 整项完成。
