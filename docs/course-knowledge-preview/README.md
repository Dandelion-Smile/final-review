# 课程知识树页面 · 独立设计预览

2026-11-14。本目录为待确认的静态 Mock 原型，不修改正式课程路由、业务页面或真实数据。

直接打开 `index.html`，或从本目录启动静态服务：

```powershell
python -m http.server 8770 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8770/>。

- 延续当前产品的深蓝侧栏、米白背景、浅色卡片；点击侧栏课程名回到课程总览。
- 主区以章节知识树为主体，右侧按笔记、资料、测试排列三个内容卡片。
- Mock 数据为 6 个章节、28 个知识点、8 份已解析资料、5 篇笔记、3 份测试；统计由数据计算。
- 默认展开前两章，支持逐章展开/收起、全部展开/收起、章节及知识点搜索；搜索自动展开匹配章节。
- 点击知识点可预览概述和来源资料；右侧内容及“查看全部”可打开本地预览弹窗。
- 侧栏可收起，窄屏显示抽屉导航和单列布局；保留键盘操作、弹窗 Escape 关闭和可见焦点。
- 无后端请求、真实文件解析、AI生成、作答提交或持久化写入；正式导航接入等待用户确认。

文件：`index.html` 为结构，`styles.css` 为样式，`mock-data.js` 为示例内容，`app.js` 为预览交互。

## 本轮验证

- 两个 JavaScript 文件通过 `node --check`。
- BrowserOS neo 验证逐章交互、全部收起为 0 章、全部展开为 6 章 / 28 个知识点。
- 搜索 `Cookie` 命中 1 章 / 2 个知识点；无匹配内容显示搜索空状态。
- 知识点弹窗显示章节、概述和来源页码；课程资料完整预览显示 8 份资料。
- 桌面侧栏可收起至 64px；手机抽屉导航打开后，点击课程名可关闭抽屉并返回总览。
- 1440px、375px、320px 视口均无页面级横向溢出；已目视检查桌面和 375px 手机截图。
