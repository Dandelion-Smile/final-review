## 更新演示

在仓库根目录重新打包：

```powershell
python scripts/build_ui_v2_demo.py
```

输出目录为 `dist/ui-v2-demo`，打包文件为 `dist/ui-v2-demo.zip`。将输出目录中上述五个文件更新到 `gh-pages` 分支后，Pages 自动构建发布。发布前检查首页、详情跳转与资源路径，发布后检查实际公网地址。

发布使用独立分支，不需要将演示提交合并到业务开发分支。不要把仓库根目录、真实上传资料、`.env` 或整个工作区作为站点内容。
