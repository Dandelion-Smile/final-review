## 打开

GitHub Pages 演示地址：<https://dandelion-smile.github.io/final-review/#/home>。发布说明见 [hosting.md](hosting.md)。

可直接在浏览器打开 `prototype.html`。若浏览器限制本地脚本或存储，可在项目根目录启动：

```powershell
python -m http.server 8767 --bind 127.0.0.1 --directory docs/ui-v2
```

然后访问 `http://127.0.0.1:8767/prototype.html#/home`。

原型不依赖前端构建、不访问业务后端、不修改真实数据；示例操作保存在当前浏览器的本地存储。右上角“重置演示”可恢复初始数据。

## 推荐体验

1. 主页 / 我的学习集 → 计算机网络总览 → 资料、笔记或测试；也可从总览直接继续阅读与作答。
2. 选择两份已就绪资料 → 生成笔记 → 配置 → 模拟生成 → 查看目录与来源。
3. 笔记 / AI 辅导中打开成果，再到相应列表找回同一内容。
4. 主页“继续作答”或测试列表“继续作答” → 切题、标记、修改答案 → 刷新恢复 → 交卷 → 结果解析 → 学习报告。
5. 独立打开日历 → 月/周切换 → 选择日期 → 打开安排 → 添加新安排。
6. 切换到没有资料的学习集，检查空状态。

真实上传、解析、AI、导出、笔记编辑、版本复核和主观题评分尚未接入；相应入口会明确说明。生成只复制本地预置内容，用于确认配置与结果的跳转方式。

## 本轮检查记录

使用 BrowserOS neo 对独立原型进行了以下检查：

- 学习集列表 → 资料 → 笔记列表 → 笔记详情；详情有 5 个章节、3 个来源。
- 返回主页保留学习集导航；进入学习集列表收起课程导航。
- 答题选项、切题、标记、刷新后的答案恢复、未答题确认及结果解析。
- 选中两份资料生成的笔记显示两个来源，且能在 AI 成果卡中找到。
- 日历月视图 42 个日期格、周视图 7 个日期格。
- 添加安排后进入所选日期的日程列表；新建学习集后进入对应资料空状态。
- 初始报告派生结果：3 次测试、24 次作答、18 次答对、75% 正确率。
- 375px 视口下主页、笔记详情、答题和日历无页面级横向溢出；桌面主页已截图检查。
- 两个 JavaScript 文件通过 `node --check`。
- 紧凑侧栏检查：展开 224px / 收起 64px，品牌左距 12px，导航字体 13px、图标 16px、行高 34px；收起后正文扩展、输入保留，刷新和切页保持收起状态；矮窗口隐藏滚动条且仍可滚动到末尾，375px 下抽屉可打开和关闭。
- 滚动显示修复：桌面正文滚动 220px、手机正文滚动 300px 时，文档滚动仍为 0，侧栏和顶栏保持在顶部；桌面完整截图与滚动后截图均无顶部空白。切页恢复正文顶部，收起导航可正常使用。

以上为设计原型检查，不代表正式后端、手机视觉或完整无障碍验收。

学习集总览已加入：默认进入课程总览，内容统计与三个模块可跳转列表，具体资料/笔记/测试复用原有预览与详情；支持编辑介绍和无数据学习集。

总览检查：主页及学习集列表的默认进入路径已指向总览；三个统计入口分别进入资料、笔记、测试列表；继续阅读/作答/结果与资料预览沿用同一实体；编辑介绍刷新后保留；高数空学习集显示 0/0/0 且不混入网络内容；375px 和 320px 无横向溢出。

导航修订：不再单列“总览”，直接点击侧栏课程名进入学习集主页；该页高亮课程名，面包屑显示“我的学习集 / 课程名”。
